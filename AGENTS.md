# Agent entry point

Before changing this repository or preparing a testing package, read the current root-level `WORKFLOW.md` and `TESTING.md`. Re-read them when resuming work; do not rely on remembered or copied versions.

`WORKFLOW.md` contains Agathos, Design, and development practices. `TESTING.md` contains this project's current tests, cumulative history, user feedback, and unresolved questions. Follow both, preserving project-specific guidance and known-good behavior.

During substantial work, provide frequent concise progress and intention updates. Make small, coherent, traceable commits. Before delivery, perform available checks, distinguish static or simulated verification from live FFXI testing, update the testing record without silently removing history, and report commit/push status and pending tests.

In testing ZIPs, include `WORKFLOW.md` and `TESTING.md` alongside the delivered addon or patch files (inside the addon folder when present), not as extra copies at the outer ZIP root.
